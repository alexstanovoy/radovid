# Every position on the radovid wire: append-only (README.md, Protocol).
#
# Protocol version 2 restarted this registry: version 1 carried the types of one game and never
# shipped. From version 2 on, one line a position postcard encodes: an enum variant index, a struct or
# struct variant field order. New variants and fields go last and their lines are appended here; a
# line is never edited or removed. Every change bumps PROTO_VERSION.
# Frozen: ClientMsg 0 Hello, ServerMsg 1 Refused, Error 0 ProtoMismatch.
